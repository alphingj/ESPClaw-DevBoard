🦞 ESPClaw-DevBoard Web Flasher

Flash ESP-Claw firmware to ESP32-DevKitC via Web Serial API (Chrome/Edge only)

⚠️ Requirements & Limitations

  • Browser: Chrome 89+ or Edge 89+ (Web Serial API required)
  • Hardware: ESP32-DevKitC with CP2102 USB-to-UART bridge (CH340 also works)
  • Driver: CP2102 VCP driver must be installed on your OS
  • Note: Classic ESP32 uses CP2102 (UART), NOT native USB - WebUSB NOT supported
  • Firmware: Pick a release below (full-flash or esp-claw package), or upload your own .bin
